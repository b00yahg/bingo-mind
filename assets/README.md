# 🎨 ASSETS FOLDER

This folder is ready for your game assets!

## 📁 Folder Structure:

- **images/balloons/** - Place balloon PNG images here
- **images/shells/** - Place shell/cup PNG images here
- **images/characters/** - Place devil, angel, Bingo character images here
- **images/weapons/** - Place knife images here
- **images/backgrounds/** - Optional background images
- **sounds/** - Place all MP3 sound effects here
- **music/** - Optional background music files

## 📄 See Full Asset List:

Check **`../ASSETS_NEEDED.md`** in the root folder for:
- Complete list of all assets with exact filenames
- Specifications (dimensions, formats, descriptions)
- Art style guidelines
- Where to get/create assets
- Checklist to track progress

## ✅ How It Works:

1. Drop your asset files into the appropriate folders
2. Use the **exact filenames** from ASSETS_NEEDED.md
3. Refresh the game in your browser
4. Assets will load automatically!

**The game works perfectly without assets** - they're just visual/audio enhancements with emoji/CSS fallbacks!
